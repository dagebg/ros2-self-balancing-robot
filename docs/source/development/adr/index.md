# Architecture decision records

Significant technical decisions are recorded as short ADRs: what was decided, why, and what was
rejected. ADRs are immutable once accepted; a changed decision gets a new ADR that supersedes the
old one.

To add one, copy {doc}`0000-template` to the next free number and add it to the list below.
